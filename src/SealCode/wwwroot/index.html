01 / Collaborative code

The same code.
Everyone in the loop.

Pair on a tricky bug or work through an interview problem. Edit together and see where everyone is thinking.

  • Live editing with shared cursors
  • Typing, selection, and copy indicators
  • Undo your changes while keeping theirs

02 / Shared whiteboard

Some ideas
need a bigger canvas.

Go from a question to a system design. Sketch the services, connect the moving parts, and refine the diagram together.

  • Infinite canvas with pan and zoom
  • Shapes, labels, databases, and queues
  • One-way and bidirectional arrows

03 / Room management

A room for
every conversation.

Create a code room or a whiteboard, copy the invitation, and bring people in. Keep the sessions you run in one place.

  • Separate code and whiteboard rooms
  • Guests join with a name and a link
  • See participants and manage your rooms

04 / Interviewer’s companion

Less searching.
Better questions.

Keep your prompts and code examples close. Browse the question library, copy a snippet, and stay focused on the person in front of you.

  • Search questions by topic or number
  • Syntax-highlighted examples, ready to copy
  • Private to admins, when enabled
